## Auth Pattern (from saas-backend + insights-dashboard exploration)

- **Login:** OAuth redirect to backend `/v1/auth/google`, `/v1/auth/microsoft`, `/v1/auth/okta`, `/v1/auth/magic-login`
- **Session:** HTTP-only cookie set by backend on OAuth callback
- **Verify:** Frontend calls `GET /v1/auth/verify` on app mount → returns user profile + agencies
- **Tenant injection:** Axios request interceptor adds `tenant_id` query param
- **Three user types:**
  - OTB Staff: `user.tenant_id === 'outoftheblue'` → access all tenants → `/customers` picker
  - Tenant Users: `user.tenant_id === '<tenant>'` → single tenant
  - Agency Users: `user.is_agency_user === true` → tenants via agency → brand chain → sidebar switcher
- **Backend guard:** `validateTenantAccessFromQuery` middleware (file: `saas-backend/src/middleware/tenantAccess/tenantAccess.middleware.js`)
- **Key insight-dashboard files for reference:**
  - Login: `src/screens/LoginScreen.jsx`
  - Auth hook: `src/hooks/useAuthenticatedUser.js`
  - Tenant hook: `src/hooks/useSelectedTenant.js`
  - Axios interceptor: `src/services/axiosTenantInterceptor.js`
  - Route guards: `src/components/App.jsx` (RequireAuth, RequireAdmin)
  - Tenant picker (OTB): `src/screens/CustomersScreen.jsx`
  - Brand switcher (agency): `src/components/common/ui-components/sidebar/SidebarHeaderDropdown.jsx`
